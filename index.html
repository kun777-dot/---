数据结构 - 排序算法

基于C语言实现 | GitHub Pages 部署

一、直接插入排序

基于"逐步构造有序子序列"的自适应排序算法，哨兵优化版

稳定排序 O(n²) O(1) 哨兵优化

二、折半插入排序

直接插入排序的改进算法，用二分查找定位插入位置，大幅减少比较次数

稳定排序 O(n²) O(1) 二分查找

三、希尔排序

缩小增量排序，先大增量粗排后小增量细排，让序列快速接近有序

不稳定排序 O(nlogn) O(1) 缩小增量

四、冒泡排序

最简单的交换类排序，V1基础版 + V2 flag优化版，含KCN/RMN统计

稳定排序 O(n²) O(1) flag优化

五、快速排序

分治交换排序，所有内部排序中平均性能最优，大幅领先冒泡排序

不稳定排序 O(nlogn) 分治算法 递归

六、简单选择排序

最基础的选择类排序，每趟选最小值交换，每趟仅一次交换确定最终位置

不稳定排序 O(n²) O(1) 最少交换

七、堆排序

基于完全二叉树的树形选择排序，建大根堆 + 堆顶交换 + 筛选调整

不稳定排序 O(nlogn) O(1) 完全二叉树

八、归并排序

分治排序，递归拆分至单元素，再逐层两两有序合并

稳定排序 O(nlogn) O(n) 分治算法
