快速排序 (Quick Sort)

分治交换排序 | 不稳定排序 | 平均O(nlogn) | 最坏O(n²)

排序思路

选第一个元素49为枢轴 → 右指针找<49的值(27)移到左边 → 左指针找>49的值(65)移到右边 → 指针相遇放回枢轴 → 递归处理左右子区间

源码 (quick_sort.c)

划分函数 Partition

int Partition(int A[], int low, int high) {
    int pivot = A[low];
    while (low < high) {
        while (low < high && A[high] >= pivot) --high;
        A[low] = A[high];
        while (low < high && A[low] <= pivot) ++low;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;
}

递归排序 QuickSort

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pivotpos = Partition(A, low, high);
        QuickSort(A, low, pivotpos - 1);
        QuickSort(A, pivotpos + 1, high);
    }
}
