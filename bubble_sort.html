公共交换函数

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
    RMN += 3;
}

V1.0：基础版本（无优化）

void BubbleSortV1(int A[], int n) {
    KCN = 0; RMN = 0;
    for (int i = 0; i < n - 1; i++) {
        for (int j = n - 1; j > i; j--) {
            KCN++;
            if (A[j - 1] > A[j])
                swap(&A[j - 1], &A[j]);
        }
    }
}

V2.0：flag优化版本（有序时提前退出）

void BubbleSortV2(int A[], int n) {
    KCN = 0; RMN = 0;
    for (int i = 0; i < n - 1; i++) {
        bool flag = false;
        for (int j = n - 1; j > i; j--) {
            KCN++;
            if (A[j - 1] > A[j]) {
                swap(&A[j - 1], &A[j]);
                flag = true;
            }
        }
        if (!flag) return;
    }
}

KCN / RMN 公式

KCN（关键字比较总次数）

最好情况（已有序）：KCN = n - 1 = 7
最坏情况（逆序）： KCN = n(n-1)/2 = 8×7/2 = 28

RMN（记录移动总次数）

最好情况（已有序）：RMN = 0
最坏情况（逆序）： RMN = 3n(n-1)/2 = 3×28 = 84
（每次交换 = 3次移动）
