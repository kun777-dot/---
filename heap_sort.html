堆排序 (Heap Sort)

树形选择排序 | 不稳定排序 | O(nlogn) | O(1)空间复杂度

算法流程

建大根堆 → 堆顶(最大值)与堆尾交换归位 → 筛选调整剩余元素为新堆 → 循环至全部有序

源码 (heap_sort.c)

筛选调整 HeapAdjust

void HeapAdjust(SqList *L, int s, int m) {
    RecordType rc = L->r[s];
    int j;
    for (j = 2 * s; j <= m; j = j * 2) {
        if (j < m && L->r[j].key < L->r[j + 1].key)
            j++;
        if (rc.key >= L->r[j].key)
            break;
        L->r[s] = L->r[j];
        s = j;
    }
    L->r[s] = rc;
}

初始建堆 CreatHeap

void CreatHeap(SqList *L) {
    int n = L->length;
    for (int i = n / 2; i > 0; i--)
        HeapAdjust(L, i, n);
}

堆排序 HeapSort

void HeapSort(SqList *L) {
    CreatHeap(L);
    for (int i = L->length; i > 1; i--) {
        RecordType temp = L->r[1];
        L->r[1] = L->r[i];
        L->r[i] = temp;
        HeapAdjust(L, 1, i - 1);
    }
}
